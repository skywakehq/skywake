## Daemon: crashes, moves, idling

Two daemons with separate roots and caches stand in for two machines. Crash: an agent writes a file every 20 ms, the daemon is killed with SIGKILL, and a new one mounts the branch again. Move: a branch is unmounted on one machine and mounted on the other; then it is claimed back while still mounted, and the old machine must turn read-only.

| idle mount, 10 s |  |  | 0 | 0 | 0 | 0.0 | 0.0 |

- PASS: kill -9: nothing older than the save window (2 s) lost
- PASS: kill -9: the restarted daemon reports the unsaved changes it found
- PASS: planned move: every write arrives on the new machine
- PASS: takeover: every saved write arrives on the new machine

- PASS: an idle mount makes no requests
