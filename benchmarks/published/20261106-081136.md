## Mount: agent workloads

This repository, committed, forked and mounted, against the same files on local disk. *Cold* is the first run on a fresh daemon with an empty chunk cache (a fresh one for each workload); *warm* runs again once the cache is full. Local and warm are the median of 3 runs, taken in turn. Writes have no cold run. Requests are those of the cold run. The daemon saves every 2 s throughout, as it would for an agent.

## Fleet: 20 agents on one machine

Forks of one base tree, all mounted on one daemon, as on a machine running many agents. Reads go through one shared chunk cache, so each chunk should come from the bucket once, however many agents read it. Writes are saved by one timer that saves every mount in turn. Then the same agents split across two machines, each with its own daemon and cache, reading through one node of the shared cache tier: still about one read per chunk. Garbage collection runs over and over while the agents write, and every branch must check out byte-for-byte afterwards.
