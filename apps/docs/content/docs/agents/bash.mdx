Agents already know bash. `@skywake/bash` gives them a shell whose disk is a Skywake branch, built on [just-bash](https://github.com/vercel-labs/just-bash). It runs in your process, with no container and no network: `ls`, `cat`, `sed`, `awk`, `jq`, `head`, `wc`, `mkdir`, `cp`, `mv` and `rm` work on the branch's files directly.

`rg`, `grep -r` and `find` are answered by the API instead of reading the tree file by file, so they stay fast on a branch with millions of files. On a namespace with a [linked index](../indexes/sync-with-branch.mdx), `rg` reads only the files that hold every trigram the pattern needs.

```bash
npm install @skywake/bash @skywake/sdk
```

## Use it as a tool

With the Vercel AI SDK:

```ts
import { createShell } from "@skywake/bash";
import { bashTool } from "@skywake/bash/ai";
import { Skywake } from "@skywake/sdk";
import { generateText, stepCountIs } from "ai";

const sky = new Skywake({ url: "https://api.skywake.dev", key: process.env.SKYWAKE_KEY! });
const branch = await sky.namespace("prod/app").branch("main").fork("agents/42");
const shell = createShell(branch);

const { text } = await generateText({
  model: "anthropic/claude-sonnet-5.5",
  tools: { bash: bashTool(shell) },
  stopWhen: stepCountIs(20),
  prompt: "Find every TODO under src and list them in TODO.md",
});
```

By default each command that changed files becomes one commit, with the command as its message. Pass `bashTool(shell, { commitEach: false })` to keep changes pending and commit them yourself with `shell.fs.commit(message)`.

## Use it over MCP

```json
{
  "mcpServers": {
    "skywake-bash": {
      "command": "npx",
      "args": ["-y", "-p", "@skywake/bash", "skywake-bash-mcp"],
      "env": {
        "SKYWAKE_URL": "https://api.skywake.dev",
        "SKYWAKE_KEY": "sw_...",
        "SKYWAKE_NAMESPACE": "prod/app",
        "SKYWAKE_BRANCH": "agents/42"
      }
    }
  }
}
```

The server offers one tool, `bash`, and commits after each command that changed files.

## Run commands yourself

```ts
const { bash, fs } = createShell(branch);
await bash.exec("rg -n 'TODO' src | head -20");
await bash.exec("mkdir -p notes && echo done > notes/today.md");
await fs.commit("Write today's notes");
```

## How it behaves

- **One view.** The shell reads the branch as of its head when the shell first reads it, until it commits. Changes others make meanwhile appear after the next commit.
- **Writes stay pending.** They are visible to later commands at once and reach the branch only on commit, all as one commit. `fs.discard()` drops them.
- **Copies are free.** `cp -r` and `mv` of files the shell has not changed copy no data.
- **The server answers a search** when it covers only files the shell has not changed. Over changed files, or with flags it does not know, the command runs in the shell instead and reads the files.
- **Supported server-side flags.** `rg`: `-i`, `-S`, `-n`, `-l`, `-F`, `-g`, `-e`. `grep -r`: `-i`, `-n`, `-l`, `-F`, `-E`, `-e`, `--include`. `find`: `-name`, `-type f|d`.
- **Limits.** Symlinks can be read but not made. A search stops at 1,000 matches and says so.
