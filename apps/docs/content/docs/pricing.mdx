Skywake Cloud bills you for what you use. Every paid plan has a monthly minimum, and that minimum is credited back against the month's usage. In the end you pay whichever is higher: the minimum or your usage.

## Plans

| Plan       | Monthly minimum | Includes                                                                          |
| ---------- | --------------- | --------------------------------------------------------------------------------- |
| Free       | None, no card   | The limits below. No paid features.                                               |
| Launch     | $16             | Usage without limits, and [pinned indexes](./indexes/pinning-and-replicas.mdx).   |
| Scale      | $128            | Launch, plus single sign-on, audit logs, IP allowlists and customer-managed keys. |
| Enterprise | Custom          | Every feature, on terms agreed with us.                                           |

## Usage

| Meter          | Price                     | Measured as                                                               |
| -------------- | ------------------------- | ------------------------------------------------------------------------- |
| Index storage  | $0.25 per GB-month        | Each index's size, sampled every hour.                                    |
| Writes         | $1.50 per GB written      | The logical bytes of every upsert, patch and delete.                      |
| Queries        | $0.75 per PB scanned      | The index's size for each read, so a query on a 10 GB index scans 10 GB.  |
| Embeddings     | $0.01 per 1,000 texts     | Each text or image Skywake [embeds](./indexes/embeddings-and-rerank.mdx). |
| Reranks        | $0.02 per 1,000 documents | Each document sent to a reranker.                                         |
| Pinned         | $0.001 per GB-hour        | The size of a pinned index for each hour it stays pinned.                 |
| Files storage  | $0.10 per GB-month        | The bytes a filesystem keeps in the bucket, after compression and dedupe. |
| File downloads | $0.12 per GB              | The bytes of every file read through the API.                             |

A GB is 2³⁰ bytes. Usage is sent to Stripe every few minutes and shows up on your next invoice. Every response has a `billing` field that tells you what that request counted.

## Files

Files and indexes are billed on the same invoice. If your organization uses only one of them, you pay only for that one.

Writing, forking, branching and committing files cost nothing. Files storage counts each filesystem's bytes in the bucket, so if the same data is stored twice in one filesystem, you pay for it once. Skywake measures each filesystem once a day, and again within the hour after it changes. Reads that a mounted daemon makes straight from the bucket are not metered yet.

## Free

The Free plan's monthly limits reset on the first day of each calendar month.

| Limit                     | Free   |
| ------------------------- | ------ |
| Stored in indexes         | 1 GB   |
| Written each month        | 1 GB   |
| Scanned each month        | 10 TB  |
| Embeddings each month     | 10,000 |
| Reranks each month        | 1,000  |
| Indexes                   | 3      |
| Files stored              | 5 GB   |
| File downloads each month | 10 GB  |
| Filesystems               | 3      |

If a request would go past a limit, or needs a paid feature, it fails with `402`, the code `payment_required` and a link to upgrade. Nothing you stored is deleted, and the limits lift as soon as you upgrade.

## The minimum

At the start of each month, you are charged the plan's minimum, and the same amount is added to your account as credit. The credit pays for that month's usage. Any credit left at the end of the month expires. If your usage costs more than the minimum, the invoice charges only the difference.

## Changing plans

You can upgrade, downgrade, cancel or update your card from **Settings → Billing** in the console.

- An upgrade takes effect at once. The difference in minimums for the rest of the month is charged right away, and credited the same way.
- A downgrade takes effect at the end of the month. Until then you keep the higher plan, and you can undo the change.
- If you cancel, the plan lasts until the end of the month, and then the account returns to Free. Usage up to that point is billed on a final invoice. You can resume before the month ends.
- If a payment fails, Stripe retries the card. The plan keeps working for 7 days. After that, the account is treated as Free until the invoice is paid.

## Self-hosting

When you run your own servers, billing is off unless you turn it on. A server with no `STRIPE_SECRET_KEY` has no plans, no limits and no paid features, and the console's billing settings show only usage by index.

If you want to charge your own users through Stripe, set these variables:

| Variable                  | Value                                                                                                                       |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `SKYWAKE_API_BILLING`     | `stripe` to turn billing on, `off` to keep it off. Defaults to `stripe` when a key is set.                                  |
| `STRIPE_SECRET_KEY`       | A secret or restricted key. Live keys are refused unless `SKYWAKE_API_BILLING_LIVE=true`.                                   |
| `STRIPE_WEBHOOK_SECRET`   | The signing secret of the webhook endpoint below.                                                                           |
| `SKYWAKE_API_CHECKOUT`    | `hosted`, the default, sends people to a Stripe Checkout page. `custom` keeps them in the console, with Stripe's card form. |
| `STRIPE_PUBLISHABLE_KEY`  | The matching publishable key. Needed only with `SKYWAKE_API_CHECKOUT=custom`.                                               |
| `SKYWAKE_API_CONSOLE_URL` | The console's address, including its base path. Checkout and the billing portal return here.                                |

You can't set `SKYWAKE_API_PRICES` together with Stripe billing, because Stripe holds the prices.

Next, create the products, prices, meters and portal settings in your Stripe account. Log in with the Stripe CLI first, then run the script below. Running it again changes nothing.

```bash
node apps/api/scripts/stripe-catalog.ts
```

Then add a webhook endpoint at `https://<api>/billing/stripe` that sends these events:

- `checkout.session.completed`
- `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted`, `customer.subscription.paused`, `customer.subscription.resumed`
- `invoice.finalized`, `invoice.paid`, `invoice.payment_failed`, `invoice.voided`, `invoice.marked_uncollectible`

With the admin token, you can put an organization on Enterprise through `PUT /v1/orgs/{org}/billing/plan`. This turns on every feature, with no limits and no Stripe subscription.
