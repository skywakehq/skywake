>
  Skywake keeps whole filesystems and search indexes in object storage, and gives every agent its
  own branch. Forking a branch copies only a pointer, so no data is copied.
</Hero>

```bash title="Three commands"
skywake new agent-37 --from main          # instant, whatever the size
skywake mount agent-37 /work              # a live folder, saved every 2 seconds
skywake merge agent-37 main               # three-way, conflicts per file
```
