  Skywake is an open-source search index that keeps its data in object storage you own. One query
  searches by meaning, keywords and filters. Run it yourself with `skywake deploy`, or use Skywake
  Cloud.
</Hero>

Set `SKYWAKE_API_KEY`, then:
